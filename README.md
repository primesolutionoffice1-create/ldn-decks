# LDN Decks

Monorepo for the LDN Decks business.

- `site/` — the live Next.js website. Deploys to Vercel with **Root Directory = `site`**.
- `brains/wiki/` — Obsidian knowledge wiki
- `brains/seo/` — SEO brain vault
- `brains/marketing/` — marketing brain vault
- `brains/ads/` — ads brain vault

Each `brains/*` folder is a self-contained Obsidian vault — open the folder in Obsidian.
