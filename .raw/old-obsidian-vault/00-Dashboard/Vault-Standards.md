# Vault Standards

## Required Properties
Every Ldndecks AI Brain note should include: type, title, created, updated, status, and tags. Tags are lowercase and hierarchical when useful.

## Naming
- Use unique filenames so wikilinks resolve without ambiguity.
- Use purpose-specific names for duplicates, such as [[Deck-Materials-Authority-Guide]] instead of a generic duplicate.
- Keep folders numbered only when the order supports navigation.

## Hub Rule
Every durable note should be linked from at least one hub, dashboard, or relationship map. If a note is not linked from a hub, it is probably a draft, source, scratch note, or archive candidate.

## Canvas Rule
Use one intentional master canvas for the operating map. Avoid root-level `Untitled.canvas` boards; move abandoned artifacts to `_Needs-Review`.

## Review Rhythm
- Weekly: update [[COMMAND-CENTER]].
- Monthly: run a graph cleanup pass for unresolved links, duplicate filenames, and orphan clusters.
- Quarterly: refresh service, city, GBP, AI search, ads, and analytics hubs.
