# Weekly Reporting Workflow

## Steps

1. Import fresh platform exports.
2. Import optional GSC/GA4/CRM context.
3. Run synthesis.
4. Review [[Weekly Client Report]].
5. Run report check.
6. Export HTML or PDF.

## Report Must Explain

- What changed.
- Why it matters.
- What is risky.
- What needs approval.
- What happens next.
