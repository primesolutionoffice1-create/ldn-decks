# Ads Brain Memory Model

## Compiled Truth

Ads Brain treats ad-platform exports as events, campaign notes as compiled
truth, and deliverables as views. A recommendation is only useful if it can be
traced back to raw source material.

## Schema Rule

Every wiki note uses `brain_schema: ads-brain.v1` so future tools can identify
Ads Brain files without guessing from folder names. Keep frontmatter flat and
use wikilinks for relationships.
