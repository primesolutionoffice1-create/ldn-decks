## Diagnosis

On the `/services/new-decks` page you have 3 JSON-LD blocks. The third block contains the problem:

```json
{
  "@context":"https://schema.org",
  "@type":"Service",
  "serviceType":"Custom Deck Construction",
  "provider":{"@id":"https://ldndecks.com/#business"},   ← BUG #1
  "areaServed":[...],
  "description":"...",
  "aggregateRating":{                                     ← BUG #2 (the cause of the error)
    "@type":"AggregateRating",
    "ratingValue":"5.0",
    "reviewCount":"41"
  }
}
```

**Why it fails:**
1. `provider` references `@id`: `https://ldndecks.com/#business`, but your Organization actually has `@id`: `https://ldndecks.com/#organization`. The reference is broken.
2. More importantly: Google does not accept `aggregateRating` directly on `Service` as an eligible review snippet — it must be on a self-standing type (Product, LocalBusiness, Organization, etc.). This produces the error "Invalid object type for field `<parent_node>`".

## Concrete remediation steps

**Step 1 — Log in to Squarespace**
Open https://account.squarespace.com and access the ldndecks site.

**Step 2 — Navigate to the affected page**
In the editor: `Pages → Services → New decks` (or go directly to ldndecks.com/services/new-decks in edit mode).

**Step 3 — Find the Code Injection block**
The JSON-LD code is injected either in:
- `Settings → Advanced → Code Injection → Header/Footer` (global code), OR
- `Page Settings (gear icon) → Advanced → Page Header Code Injection` (per-page code)

The /services/new-decks page has page-specific markup, so it is most likely in **Page Settings → Advanced**.

**Step 4 — Replace the Service block**
Find the block that starts with `"@type":"Service"` and replace it with this corrected version:

```html
<script type="application/ld+json">
{
  "@context":"https://schema.org",
  "@type":"Service",
  "name":"Custom Deck Construction",
  "serviceType":"Custom Deck Construction",
  "provider":{"@id":"https://ldndecks.com/#organization"},
  "areaServed":[
    {"@type":"AdministrativeArea","name":"Loudoun County, VA"},
    {"@type":"AdministrativeArea","name":"Fairfax County, VA"},
    {"@type":"AdministrativeArea","name":"Prince William County, VA"}
  ],
  "description":"From concept to completion, we design and build fully custom decks tailored to your space, style, and budget in Northern Virginia."
}
</script>
```

**Two key changes:**
- `provider.@id` changed from `#business` → `#organization` (to match the existing Organization).
- Removed `aggregateRating` from `Service`. The aggregate rating should be on `GeneralContractor` (Organization) — added in step 5.

**Step 5 — Move aggregateRating onto the Organization (in global Code Injection → Header)**
Find the `"@type":"GeneralContractor"` block and add before the final `}`:

```json
,"aggregateRating":{
  "@type":"AggregateRating",
  "ratingValue":"5.0",
  "reviewCount":"41"
}
```

⚠️ **Important:** To remain compliant with Google's policies, make sure you have at least a few real reviews visibly displayed on the page (Google verifies this). Otherwise, other warnings may appear.

**Step 6 — Save & publish**
Click Save in Code Injection, then publish the page.

**Step 7 — Verify**
1. Open https://search.google.com/test/rich-results
2. Enter: `https://ldndecks.com/services/new-decks`
3. Confirm that no more errors appear.

**Step 8 — Validate Fix in Search Console**
Return to the Search Console tab and click the **VALIDATE FIX** button. Google will recrawl the pages over the next few days.
