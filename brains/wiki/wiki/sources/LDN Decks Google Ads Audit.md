# LDN Decks Google Ads Audit

## Source Summary

The Google Ads audit identifies paid-search waste and landing-page gaps. It supports the revenue system and should feed the next conversion and landing-page work.

## Main Findings

- PMAX cannibalization exists.
- Brand traffic overlap exists.
- Quality Score is below 7 on many keywords.
- Landing page relevance is weak in places.
- Irrelevant search terms are creating spend waste.

## Priority Actions

- Add negative keywords.
- Improve landing-page relevance.
- Build a custom deck landing page.
- Build a deck repair landing page.
