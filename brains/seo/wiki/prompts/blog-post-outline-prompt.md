# Blog Post Outline Prompt

> AI prompt extracted from [[content-blog-post-outline|Content : Blog Post Outline]]. Use as a reusable building block. Test with your own client's facts before shipping output.

## Prompt

You will be acting as a world-class educational SEO blog writer and expert in the local city and business in the attached customer avator. Your task is to write a detailed script outline for a blog post. This post will primarily target the customer avatar

Please write the outline, 1 section at a time. After each section, ask for my feedback and approval before moving on to the next one. I will provide my input, and once I’m satisfied with each section, you can proceed to write the next one. If you need any additional information or clarification to write the outline effectively, please ask.

Article Structure

**1\. Title & Meta Elements**

SEO Title Tag (55-60 characters)

Meta Description (150-160 characters)

URL Structure

H1 Tag (incorporating primary keyword)

**2\. Introduction Block (150-200 words)**

Hook Options:

Question-based hook

Statistical hook with citation

Story-based hook

Problem-solution hook

Future-pacing hook

Keyword incorporation

Clear value proposition

Topic relevance signals

Article roadmap/preview

**3\. Featured Snippet Target (100-150 words)**

First, ask me specifically which query / question to target for the featured snippet here. Provide some suggestions. Ask me to give you the current featured snippet for this question. Also, ask if I would like to skip this section.

Direct answer to main search query

Structured for featured snippet optimization

Bulleted or numbered list

Clear, concise definitions

Schema markup recommendations

**4\. Main Content Sections**

H2 Sections (incorporate secondary keywords)

Supporting H3 subsections

Key points and evidence

Expert quotes/citations

Statistics and data

Visual content recommendations

Internal linking opportunities

External authority links

**5\. User Experience Elements**

Content breaks (every 300 words)

Transition sentences

Bullet points and lists

Table of contents

Custom graphics/images

Interactive elements

**6\. Trust Building Elements**

Expert credentials

Case studies

Social proof

Data visualization

Authority citations

**7\. Call-to-Action Framework**

Primary CTA

Secondary CTAs

Lead magnet opportunity

Contact information

Next steps

**8\. Technical SEO Elements**

Word count target (based on SERP analysis)

Keyword density guidelines

Image alt text

Schema markup

Mobile optimization notes

Content Guidelines

Natural keyword placement

E-A-T signals

Reading level optimization

Content freshness signals

User intent alignment

Semantic relevance

Quality Control Checklist

Keyword optimization

Content depth

Technical SEO elements

User experience

Mobile responsiveness

Loading speed considerations

Remember, for this blog post our goal is to write it for both readers and optimized for Google’s algorithm so we can rank it.

I will give you the target keyword and the title tag.
