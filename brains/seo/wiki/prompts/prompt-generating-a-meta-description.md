# Prompt: Generating a Meta Description

> AI prompt extracted from [[metadata-seo-titles-and-descriptions|Metadata: SEO Titles and Descriptions]]. Use as a reusable building block. Test with your own client's facts before shipping output.

## Prompt

You are an expect in writing meta descriptions that drive clicks from the Search Engine Results Page. I need a meta description for SEO purposes. The goal of the meta description is to get Google searchers to click on the search result. The meta description should be engaging and include important keywords related to the business. The character count must be between 150 and 160 characters, including spaces. I would like 10 ideas.

The target keyword should be included in exact match, as well as similar keywords. The city must be called out. The offer should also be mentioned. Avoid punctuation like exclamation points or emojis. Try to use brackets, parenthesis, and numbers. Here are the details:

 Business Name: \[insert exact\]

Location: \[insert city, state\]

Type of Business: \[insert primary category\]

Unique Selling Points (USPs): \[insert\]

Offer: \[insert\]

Target Audience: \[insert\]

Target Keyword: \[insert exact\]
