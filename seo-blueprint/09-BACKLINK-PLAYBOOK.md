# Phase 9 — Backlink Playbook (NoVA-Specific)

This is not a generic "guest post on home blogs" list. Every target below has been chosen for **NoVA relevance, real linking power, or trust transfer specific to the deck-building category**.

---

## The 5 buckets

1. **Local citations** (NAP + link) — directory listings; Tier 1 covered in [04-LOCAL-SEO.md](04-LOCAL-SEO.md)
2. **Industry / association** — earned by membership or certification
3. **Local media + community** — earned by relationships and PR
4. **Partnerships / supplier links** — earned by being a Trex Pro, supplier customer, etc.
5. **Content-driven outreach** — earned by being a citable source

Every backlink should pass one of three tests:
- **Topically relevant** (deck, outdoor living, home improvement, NoVA real estate)
- **Geographically relevant** (NoVA, DMV, Loudoun, Fairfax, etc.)
- **Trust signal** (BBB, association, license body, manufacturer partner)

Stay away from: PBNs, bulk niche-edit buys, comment spam, irrelevant "blog network" outreach.

## Backlink monitoring + disavow

You already have Ahrefs verification (`ahrefs_eddf...`). Set up:

1. **Weekly Ahrefs alert** for new referring domains (auto-email)
2. **Monthly disavow review** — flag spammy links (PBN footprint, foreign-language casino/health, generic directory bombs)
3. **Quarterly competitor backlink gap analysis** — Ahrefs Site Explorer → Battlefield, Fortress, Distinctive Deck Designs → "Best by links" → see who's linking to them but not you

---

## Toxic link signals to disavow

If you see these, disavow:
- Links from sites with TLDs `.tk`, `.ml`, `.cn` not in your service area
- Sites with > 50 outbound links per page that include yours among gambling/pharma/loan offers
- Comment spam from blog comment threads with no editorial vetting
- Forum signature links from low-quality forums
- Article-spinner sites (recognizable by garbled English)

Don't pre-emptively disavow good directory links just because they're nofollow — Google uses them for entity reinforcement.
