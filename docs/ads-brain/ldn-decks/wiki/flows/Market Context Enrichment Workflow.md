# Market Context Enrichment Workflow

## DataForSEO

Use DataForSEO for landing-page SERP context, competitor SERP snapshots, keyword
demand, and search intent. It enriches paid-media decisions but does not
replace ad-platform performance exports.

## Google Search Console

Use GSC exports for landing-page query context, organic demand, brand/non-brand
query language, and page-level search quality.

## Rule

Do not write credentials into the vault. Use environment variables or manual
CSV exports.
