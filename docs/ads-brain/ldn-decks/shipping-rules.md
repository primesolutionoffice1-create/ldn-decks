# Ads Brain Shipping Rules

Read first. Write second. Verify third.

## Required Before Recommendations

- Identify source files.
- State confidence.
- Check tracking/privacy readiness.
- Check learning phase risk.
- Write the rollback path.

## Required Before Reports

- Verify raw exports are in `.raw/`.
- Verify source notes exist.
- Verify generated deliverables cite sources.
- Run report check before producing a client-facing PDF or HTML.

## Required Before Account Changes

Ads Brain V1 does not change accounts. If a human chooses to execute outside
the tool, the decision note must include:

- owner
- account/platform
- source
- expected impact
- risk
- rollback
- approval state
