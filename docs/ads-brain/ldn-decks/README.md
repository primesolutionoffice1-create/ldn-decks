# LDN Decks Ads Brain

This folder is an Obsidian vault for paid-media account memory, campaign
exports, tracking risk, creative testing, budget pacing, and weekly reports.

## Start Here

1. Open this folder as an Obsidian vault.
2. Read `wiki/hot.md`.
3. Read `wiki/index.md`.
4. Follow [[Start Here]].

## What Goes In

- Google, Meta, YouTube, TikTok, LinkedIn, Microsoft, and Apple Ads exports.
- GA4/GSC and landing-page context.
- Tracking and attribution notes.
- Creative test history.
- Weekly client reports.
- Human-approved optimization decisions.

## What Does Not Go In

- API keys.
- OAuth tokens.
- Passwords.
- Unsanitized customer PII.
- Live account mutation instructions without approval.
