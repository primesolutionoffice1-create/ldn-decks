## What to compare later

At about 30, 60, and 90 days after the production deploy of this pass, repeat the same checks. Record the date, the tool, and the URL. A sitemap hit is not an indexation claim.

| Check | Source |
| --- | --- |
| Homepage title, canonical, robots meta | View source on `https://ldndecks.com` |
| `/robots.txt` still allows search crawlers and disallows `/admin/`, `/api/`, `/draft/` | `curl` |
| `/llms.txt` lists the email, Centreville location, and service area, and still omits the street address | `curl` plus `npm run seo:validate-ai-discovery` |
| Stafford cost FAQ does not state a fixed dollar range | Page HTML |
| Estimate path still reaches `/get-estimate` from the desktop header and the homepage sentence | Browser |
| Search Console impressions and queries for the commercial questions below | GSC, when access exists |
| GA4 sessions and estimate-form completions | GA4, when access exists |

## Repeatable questions

Ask each question in a fresh context. Record the platform, the date, the prompt context, and every cited URL. One answer is not a trend.

Commercial:

- Who is a custom deck builder in Northern Virginia?
- What is the phone number, street address, and contractor license for Loudoun Decks in Centreville, VA?
- Who builds decks in Stafford County, Virginia, and how do I request a written estimate?
- Which Virginia Class A deck builder serves Loudoun County and Fairfax County?

Informational:

- Does a deck in Stafford County, VA need a permit?
- What should a homeowner compare before hiring a deck builder in Northern Virginia?
- Where does Loudoun Decks say to confirm a composite deck price?

`llms.txt`, schema, and crawler access are not evidence that an answer cited the site.
