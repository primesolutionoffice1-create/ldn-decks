## Findings

### P1 — `llms.txt` omitted verified identity

- File: `public/llms.txt`
- Evidence: company facts listed Centreville and the phone, but not `office@ldndecks.com` or the county list in `src/lib/business.js`. The blog was described as "40+" while `blogPosts` contains 134 posts. `scripts/validate-ai-discovery.mjs` forbids the street number and street name in `llms.txt`.
- Impact: an AI or analyst quoting `llms.txt` would miss the email and the service-area list. Confidence: high.
- Fix: add the email, the Centreville location with a pointer to the contact page, and the `areaServed` list. Say 130+. Leave the street address on the visible pages only.

### P1 — Northern Virginia builder page had no short factual answer

- File: `src/app/deck-builder-northern-virginia/page.js`
- Evidence: `llms-full.txt` treats this URL as a primary deck-builder answer, and the page had no `GeoAnswerBlock`. County hubs such as Loudoun already use that block.
- Impact: the commercial question is answered only inside long sections. Confidence: high.
- Fix: add one answer built from `BUSINESS`.

### P1 — Homepage explanatory copy did not state license, address, or the estimate path

- File: `src/components/HomeSEOContent.jsx`
- Evidence: the first paragraph calls the company a local contractor and links to guides. It does not state the license, address, phone, or `/get-estimate`.
- Impact: the HTML answer is weaker than the footer license line. Confidence: high.
- Fix: add one sentence from `BUSINESS`.

### P1 — Desktop header had no estimate link

- File: `src/components/Header.jsx`
- Evidence: `/get-estimate` is in the mobile bar and the homepage hero. The desktop nav ends at Call Now.
- Impact: a desktop visitor in the nav has to hunt for the estimate. Confidence: high.
- Fix: add a text link beside Call Now, hidden at the same width where the desktop nav collapses. Mobile already has Estimate.

### P2 — Showcase noindex flag was ignored

- Files: `src/app/showcase/[slug]/page.js`, `src/lib/seo.js`
- Evidence: `generateMetadata` passed `robots: { index: false }`. `buildMetadata` only reads `noIndex`. The rooftop page is still noindex today because `seo.js` hard-codes that path.
- Impact: a future slug using the same flag would be indexable. Confidence: high.
- Fix: pass `noIndex`.

### P2 — Founder job title disagreed with the entity source

- Files: `src/components/TeamGrid.jsx`, `src/components/ArticleSchema.jsx`, `src/lib/business.js`
- Evidence: `BUSINESS.founder.jobTitle` is "Founder & Lead Contractor". Team and article schema emitted "Owner & Lead Designer" on the same `@id`.
- Impact: conflicting Person signals. Confidence: high.
- Fix: read the title from `business.js`. The visible team role uses the same string.

### P2 — Placeholder award in Person JSON-LD

- File: `src/components/TeamGrid.jsx`
- Evidence: `award` included "Google Business Profile reviews (verify current count on Google Maps)".
- Impact: structured data contained an instruction, not an award. Confidence: high.
- Fix: remove the `award` array. Do not replace it with an unverified claim.

### P2 — Stafford cost FAQ stated a fixed range

- File: `src/app/near-you/stafford-county/page.js`
- Evidence: the FAQ said a 300 sq ft composite deck runs $14,000–$26,000 and that Stafford is 10–15% cheaper. The same page had a "Deck Cost in Stafford County (2026)" table with that range and four more ranges. `business.js` has no approved price. `llms.txt` says not to cite a fixed range without owner-approved evidence. Stafford was the county hub without a `GeoAnswerBlock`.
- Impact: a quotable price the site's own policy does not support. Confidence: high for the policy conflict. The original range may have been editorial; it is not in the identity source.
- Fix: point the FAQ and the cost section at the cost guide and the estimate. Remove the price table. Add a factual answer block.

### P2 — Stale static robots file

- File: `public/robots.txt`
- Evidence: live `/robots.txt` matches `src/app/robots.js` (`User-Agent: Amazonbot` is present; the static file's comment header is not). `x-matched-path: /robots.txt`.
- Impact: two sources of truth. Confidence: high.
- Fix: delete the static file.

### P2 — AI index promoted a noindex URL

- File: `public/llms-full.txt`
- Evidence: it linked `/showcase/rooftop-deck-washington-dc`. That URL is noindex and excluded from the sitemap.
- Impact: discovery files disagree with the indexation policy. Confidence: high.
- Fix: keep the note, drop it as a preferred link.

### P3 — Default Open Graph image ratio

- File: `src/app/layout.js`
- Evidence: root `openGraph.images` was `/home-page-ldn.webp` (1536×1024). `src/lib/seo.js` documents `/og-default.webp` as the 1200×630 asset. Pages using `buildMetadata` already prefer the sized asset.
- Impact: routes that inherit the root image can preview at the wrong ratio. Confidence: high.
- Fix: point the root default at `/og-default.webp`.
