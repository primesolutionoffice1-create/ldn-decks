- 0 repair cost ranges are verified.

  - `/composite-deck-cost-northern-virginia`

- 1 page is proof-incomplete:

Until this evidence arrives, do not publish stronger project-proof claims, repair warranties, exact repair pricing, before/after proof, or real-project cost language.

### P0 — Live Trust Claim Synchronization

The live site still exposes some claim patterns that should match the source-safe local language before the next deploy:

- fixed warranty count claims should become written warranty-term language unless exact terms are verified.
- exact review counts should be quoted only when pulled from or verified against the public live profile.
- “real project” and “completed project” examples should stay gated until owner records connect scope, city, month/year, material, images, and cost/range.
- AI-facing files should avoid turning unverifiable trust claims into extractable facts.

### P1 — Conversion and SXO

Money pages are structurally strong. The next gains come from tightening the path:

- keep calculators high on all cost pages.
- make `/get-estimate` the preferred written-estimate destination instead of older `/contact` CTAs where possible.
- keep financing language compliance-safe.
- add “when not to buy / when replacement is smarter” framing across repair, resurfacing, and replacement pages.
- use proof modules only from verified evidence data, not hardcoded copy.

### P1 — Maps / GBP Operations

Map-pack growth is now mostly operational:

- review response cadence.
- Q&A completion.
